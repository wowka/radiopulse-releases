# RadioPulse by D.W.S. — випуски

Готові версії програм **RadioPulse** (плеєр для станцій) і **RadioPulse Monitor** (сервер моніторингу ефіру).
Розробка — [D.W.S.](https://dws.com.ua)

Завантажити останню версію: розділ **[Releases](https://github.com/wowka/radiopulse-releases/releases)**.

Починаючи з плеєра 2.3 і монітора 1.1, програми самі перевіряють цей розділ і встановлюють лише оновлення, підписані ключем D.W.S. Файли з іншим підписом або без підпису не встановлюються.
